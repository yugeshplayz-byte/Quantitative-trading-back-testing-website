# Real market data goes here

Drop CSV files such as `MNQ.csv`, `MNQ_1m.csv`, `MES.csv` in this folder (they are git-ignored, so your data is never committed).
Optional `events.csv` (`date,event,time`) enables event analysis on real data.

See [docs/REAL_DATA.md](../../../docs/REAL_DATA.md) for the exact format and conventions.
